## 2. 论文要点

- 题目：基于多输出树集成与条件生成模型的啤酒风味预测、解析与设计；
- 结构：摘要、问题重述、问题分析、模型假设与符号说明、数据预处理、问题一/二/三模型建立与求解、模型分析检验（灵敏度与稳健性）、模型评价与推广、参考文献、附录；
- 三问核心结果：
  - 问题一：Extra Trees 15 折重复 CV R²=0.2125±0.0230、MAE=0.3477、分级 ±1=0.9024、Kappa=0.2893；给出 250×50 的 0–6 分级答案表；
  - 问题二：共表达图 231 节点/641 边/60 社区；Top-1 入选频率 0.744、Top-3 0.556、模块级 0.709；化学来源可解释 146/150、官方符号一致 77/77；
  - 问题三：cVAE 重构 R²=0.929、生成谱风格分类准确率 0.691（随机 0.045）；5 对跨风格迁移全部“缺陷零恶化、零超阈值”；
  - 灵敏度：问题三缺陷约束在全部超参数变体下成立；问题一对 0–10% 随机缺失稳健。
