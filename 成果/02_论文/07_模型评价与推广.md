# 九、模型评价与推广

## 9.1 模型优点

1. **完整闭环、前后呼应**：问题一的多输出树集成不仅给出 0–6 分级答案，还固化为问题三的感官代理；问题二的 Top-3、共表达模块与阈值成为问题三的约束来源；三问通过“预测—解释—设计”形成闭环，而不是三份互不相关的模型堆叠。
2. **小样本条件下的稳健设计**：问题一用重复分层交叉验证（5 折×3 次）报告均值±标准差，并做缺失处理敏感性（五种插补方式 R² 差异 <0.002）；问题二用 25 次重采样量化 Top-3 稳定性，明确区分“稳定核心”与“不稳定成分”；问题三用风格后验采样替代先验采样（风格分类准确率 0.221→0.691），并用 best-of-K 与阈值投影保证约束。
3. **可解释性与可约束性并重**：问题一给出置换重要性 Top20、PDP 与外部 MDI 对照；问题二用共表达图 + 模块多样性约束缓解参考论文指出的共线性重要性偏差，并用阈值/来源/符号一致性核验化学合理性（146/150 来源可解释、77/77 符号一致）；问题三把缺陷阈值写成硬约束，保证 5 对迁移全部“零恶化、零超阈值”。
4. **全流程可复现、数字可追溯**：所有结果由 `成果/code/` 脚本以固定种子（42）生成，结果落盘到 `成果/results/`，论文每个数字都能对应到具体文件；数据审计（逐列变换、相关矩阵复现、字段映射）先于建模完成，避免了“用错列/用错量纲”的根本性错误。

## 9.2 模型不足

1. **感官目标噪声大、绝对精度有限**：受 250 样本与品评噪声限制，问题一 15 折 CV 的 R² 仅 0.2125，花香酯类、DMS 等阈值型/低变异维度 R² 接近 0；0–6 原始整数不可恢复，分级结果依赖映射假设（min–max 下高等级召回为 0）。
2. **Top-3 精确组成不稳定**：问题二 Top-3 平均入选频率 0.556、跨方法 Jaccard 0.167，说明“第二、第三关键化合物”本质不确定；共线性与证据口径差异是主因，本文只能以“稳定核心 + 模块级结论”缓解，无法完全消除。
3. **生成谱过平滑、缺陷投影扭曲分布**：问题三生成谱的代理画像 MAE（0.057）低于真实样品围绕风格均值的偏差（0.113），多样性不足；真实数据本身 DMS/Diacetyl 超阈值比例高达 59.3%/41.6%，阈值投影后大量样品堆在阈值附近，是“合格生成”与“真实分布”的权衡。
4. **验证仍为 in-silico**：问题三全部评价依赖问题一代理、风格分类器、MMD 与 7.csv 消费者描述符代理，没有真实品评实验；消费者描述符本身也是 RateBeer 统计量，不能替代真实感官实验。

## 9.3 模型推广

1. **方法层面**：本文“多输出树集成 + 共表达图多证据集成 + 条件生成 + 阈值硬约束”的框架可直接迁移到其他“化学成分—感官/功能品质”问题，如葡萄酒、咖啡、茶叶、乳制品、香精香料的风味预测与配方设计；只需替换特征表、感官维度与阈值表。
2. **工业质检与配方优化**：问题一的代理模型可用于“给定化学检测结果，快速预判感官画像”，降低品评成本；问题三的条件生成 + 约束可扩展为“目标风味 → 候选配方”的逆向设计，把缺陷阈值、成本、法规限制写成约束，形成可落地的配方优化器。
3. **数据需求与采集建议**：若有条件扩充数据，建议优先增加**小风格样本**（Brut、Faro 等 n≤4 的风格）与**缺陷化合物浓度梯度**（当前真实数据缺陷比例高但分布集中），并保留品评员原始 0–6 整数分，以消除本文分级假设这一最大不确定性。
4. **模型升级方向**：问题一可改用有序分类/等级校准提升高等级召回；问题二可引入文献先验与分组置换重要性进一步稳定 Top-3；问题三可改用条件扩散模型/条件归一化流提升多样性，并用“分布保真 vs 缺陷安全”的多目标评价框架替代单一代理指标。

## 9.4 结论

本文在 250 个样品、231 维混合量纲特征、50 维相关输出的严苛条件下，完成了从“预测”到“解释”再到“设计”的完整建模：问题一给出可复现的 0–6 分级答案与化学–感官代理；问题二给出带稳定性标注的 Top-3 与模块级结论，并揭示同名缺陷化合物未被统计方法选中的重要现象；问题三实现风格条件生成与跨风格迁移，在全部 5 对迁移上满足“缺陷不恶化、不超阈值”。方法的可复现性、约束可解释性与诚实的局限声明，使其既可作为本届赛题的完整答卷，也可作为同类风味建模问题的可复用框架。
