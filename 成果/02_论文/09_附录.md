```python
order = np.argsort(-score, axis=0)
for j in range(score.shape[1]):
    chosen, used = [], set()
    for i in order[:, j]:
        c = chem_cols[i]
        if module[c] in used:
            continue
        chosen.append(c); used.add(module[c])
        if len(chosen) == 3:
            break
```
