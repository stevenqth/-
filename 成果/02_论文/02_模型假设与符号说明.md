# 三、模型假设与符号说明

## 3.1 模型假设

1. **样本口径假设**：题面所述“226 种不同啤酒”系“226 项化学性质”的误读；本文以数据的 250 个唯一样本为准（该结论已由参考论文 Methods 证实：250 款啤酒、22 个风格、226 chemical properties + 5 derived）。
2. **输入数值假设**：`1.csv` 给定数值为建模输入；其逐列变换方式按数据字典 4.1 的分类处理——37 列经 `8.xlsx` 校准浓度逐元素证实为 log10、33 列为原始浓度、145 列因存在负值推断为 log10、16 列非负且无对照按原始量纲处理。未对未校准列强行反变换，以避免引入额外误差。
3. **目标口径假设**：`4.csv` 的 50 个感官列为“各品评员分数按该品评员标准差缩放并均值中心化后取平均”的 z 分数（参考论文 Methods）。0–6 原始整数分未随附件提供，本文的 0–6 分级是**明示映射假设**：主口径为训练折 min–max 线性映射到 [0,6] 后四舍五入，备选口径为训练折分位等频切分；分级结果不能反推原始品评整数分。
4. **品评卡假设**：`3.xlsx` 的 12 个品评表只用于定义感官维度与 0–6 刻度，其分数不作为标签来源；56 个评分项映射到 `4.csv` 的 50 个感官列，2 个乙醛评分项无对应标签。
5. **缺失机制假设**：`1.csv` 的 73 个缺失格为完全随机缺失（MCAR）；主口径为折内中位数插补 + 缺失指示，敏感性分析另比较训练均值、中位数、中位数+指示、IterativeImputer 与 HistGBDT 原生 NaN；真实缺失率仅 0.13%，对结论影响有限。
6. **结构先验假设**：`2.csv`/`5.csv`/`6.csv` 为 Spearman 相关矩阵，与 `1.csv` 同源，只作为结构先验与外部证据使用，不当作独立特征输入（避免信息泄漏）；`8.xlsx` 的 GBM MDI/SHAP 来自参考论文的 RateBeer 消费者喜好模型，仅作外部对照。
7. **风格标签假设**：`tasting_category_fine` 的 22 个风格标签准确代表对应啤酒风格；小样本风格（如 Brut n=4、Faro n=3）的结论需谨慎外推。
8. **缺陷阈值假设**：DMS、Diacetyl、4VG 的阈值取自 `8.xlsx`/参考论文阈值表（单位分别为 µg/L、mg/L、mg/L）；trans-2-nonenal 无统一官方阈值，按“不劣于源样品”处理；Stale hops 无对应化学列，以问题一代理模型的感官预测作软约束。
9. **生成任务假设**：问题三生成的是“条件分布样本”，同一风格下存在多条合理化合物谱，不追求唯一正确答案；所有评价均为 in-silico（代理模型、风格分类器、分布距离、消费者描述符代理），不等价于真实品评实验。
10. **可复现假设**：所有随机过程固定随机种子（42），脚本、数据版本与运行环境记录在 `成果/code/` 与 `成果/results/`，论文中每个数字均可由脚本复跑得到。

## 3.2 符号说明

| 符号 | 含义 | 单位/取值 |
| --- | --- | --- |
| $n$ | 样品数 | 250 |
| $p$ | 化学/理化特征数 | 231 |
| $q$ | 感官维度数 | 50 |
| $\mathbf{X}\in\mathbb{R}^{n\times p}$ | 化学特征矩阵 | 经逐列变换/插补后的输入 |
| $\mathbf{Y}\in\mathbb{R}^{n\times q}$ | 感官目标矩阵 | 逐品评员 z 分数平均 |
| $s_i$ | 第 $i$ 个样品的风格标签 | 22 类 |
| $v_{ij}$ | `1.csv` 原始给定值 | 原始量纲 |

| $Z_{ij}$ | 生成空间值 | $(M_{ij}-\mu_j)/\sigma_j$ |
| $\mu_j,\sigma_j$ | 第 $j$ 列均值/标准差 | 用于反变换 |

| $f$ | Top-3 入选频率 | 25 次重采样中的频率 |
| $J$ | Jaccard 系数 | 两集合交集/并集 |
| MMD | 最大均值差异 | RBF 核，越小越接近 |
