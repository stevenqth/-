## 2. NSGA-II 应怎样理解

设所有目标都取最小值。如果方案 A 在每个目标上均不差于 B，且至少一项更好，则 A 支配 B。Pareto 集合保留无法通过这种比较淘汰的方案，展示“要改善一项，需要牺牲多少另一项”。决策偏好在获得前沿后再引入。

NSGA-II 的关键操作是：非支配排序确定优先等级；拥挤距离维持前沿分布；二元锦标赛选择父代；交叉和变异产生子代；父子代联合选择保留精英。

本项目使用 MATLAB **`gamultiobj` 的受控精英 NSGA-II 变体**，不能写成自行复现 Deb 原版 NSGA-II。官方依据：[算法说明](https://www.mathworks.com/help/gads/gamultiobj-algorithm.html)、[函数接口与约束格式](https://www.mathworks.com/help/gads/gamultiobj.html)、[参数效果](https://www.mathworks.com/help/gads/gamultiobj-options-effects.html)（访问日期 2026-10-29）。原始论文：Deb et al., 2002, *A Fast and Elitist Multiobjective Genetic Algorithm: NSGA-II*, IEEE TEC 6(2), 182–197，[DOI](https://doi.org/10.1109/4235.996017)。

## 3. 本次新增模型的范围与假设

这是一份**基于真实附件数据的独立多目标扩展示例**，不宣称复现或优于原有 cVAE。为让每个参数可解释，先在三参数候选族上运行；未来有可靠 cVAE 权重后，可将候选生成函数替换为潜空间解码器。

示例选择 `Pils/Lager → Tripel`。源风格共 11 个样品，目标风格共 28 个。源样品在标准化化学距离下选取最接近源风格均值的真实样品：`beer=218`，附件第 23 行。目标化学原型为目标风格各列中位数，目标感官画像为 `4.csv` 的目标风格均值。

**假设**：附件坐标中的插值与参数化调整可用于探索候选化学画像；它不是物料配方或物理混酒公式。风格中位数画像未必对应可酿造样品，未加入质量守恒、反应动力学、组分耦合、派生总量一致性或工艺成本约束。不能把本次输出直接写成投料方案。

三个决策变量均在 `[0,1]`：

| 变量 | 含义 | 操作 |
| --- | --- | --- |
| alpha | 向目标风格原型迁移的强度 | 源画像与目标中位数在附件坐标中插值 |
| beta | 四类化学缺陷进一步削减强度 | 浓度投影后再乘 `2^(-beta)`，范围为投影浓度的 50%–100% |
| gamma | 陈旧酒花代理调节强度 | 把一个非缺陷、非派生总量的化合物向经验边界移动 |

gamma 的化合物按代理系数与 1%–99% 经验范围内可达到的预测下降量选择，本次是 `n.hexanol`，目标边界为附件坐标 `4.18601070486`。这是模型相关性方向，**不是已证实的因果作用**。不得据此断言实际减少/增加该化合物必然改善陈旧酒花味。

## 4. 正确处理浓度、感官代理与缺陷约束

`1.csv` 不是全部原浓度，也不是全部 log10。四个缺陷列经核验表逐项检查：

| 列 | 附件坐标 | 用于约束的浓度 | 阈值及单位 |
| --- | --- | --- | --- |
| DMS | log10(C) | `10^v` | 17.25 µg/L |
| X2.3.butanedione | 原浓度 | `v` | 0.29925 mg/L |
| X4VG | log10(C) | `10^v` | 0.206333333 mg/L |
| X.E..2.nonenal | 原浓度 | `v` | 缺失，仅与源浓度比较 |

对缺陷 j 定义 `L_j=0.95*min(C_source,j,T_j)`，无阈值时取 `T_j=Inf`。将插值候选的缺陷浓度修正为：

`C_j = min(C_candidate,j,L_j) * 2^(-beta)`。

再按原列变换写回附件坐标。由构造保证四项浓度不高于源样品，有阈值的三项也不超阈值。`0.95`、`0.5` 削减下限均为设计参数，后续需灵敏度分析，不是自然常数。

感官代理是强正则 Ridge：训练折内中位数插补、1%–99% 截尾、标准化，之后预测 50 个感官目标。优化时同样对预测输入截尾，化学硬约束仍在真实候选浓度上计算。所有目标与约束统一评估**修正后的最终候选**。

新增硬约束为：

`c(u) = [pred_stale(u)-pred_stale(source)] / sd_stale <= 0`。

求解和后验检查容差均为 `1e-8`。如果没有可行解，代码报错并停止推荐，不自动放宽约束。该约束只约束代理预测，不能替代真实品评证据。

## 5. 三个优化目标

记最终候选附件坐标为 v，标准化尺度为 s，代理感官输出为 yhat，目标均值为 yt，感官样本标准差为 sy。

| 目标 | 公式 | 解读 |
| --- | --- | --- |
| f1 感官偏差 | `mean(((yhat-yt)./sy).^2)` | 相对目标风格画像的标准化均方偏差，越小越好 |
| f2 调整幅度 | `sqrt(mean(((v-source)./s).^2))` | 化学画像改变量的代理，越小越好；不是人民币成本 |
| f3 相对缺陷负荷 | `mean(C_j/L_j)` | 四个化学缺陷相对于各自上限的负荷，越小越好 |

f3 不是毒理学风险，也不含 stale_hops，后者单独作为约束。这里 f3 在 0.5–1 之间；它与 f2 有潜在冲突，而不是用加权和提前把多目标压成一个总分。

## 7. Pareto 前沿如何支持决策

先求解，再决策：从可行前沿读取各目标最小值/最大值，归一化至 0–1；恒定目标排除，避免除以零。采用加权 TOPSIS，即比较方案到理想点与最差点的距离；贴近理想且远离最差的方案得分高。权重进入平方距离，而非预先加总优化目标。

| 偏好 | 感官偏差 | 调整幅度 | 缺陷负荷 |
| --- | ---: | ---: | ---: |
| 均衡 | 1/3 | 1/3 | 1/3 |
| 感官优先 | 0.6 | 0.2 | 0.2 |
| 少改动 | 0.2 | 0.6 | 0.2 |
| 低缺陷 | 0.2 | 0.2 | 0.6 |

这些权重是敏感性场景，尚未经用户确定。TOPSIS 是一条明确的选择规则，不代表客观唯一最优；结果依赖前沿采样、归一化范围和偏好。未把“离理想点最近”错误称为几何膝点。
