# 啤酒化学与风味分析修订版

本版在队友原成果基础上，重写可移植运行入口，实际重跑三问，并加入用户提供的 Kaggle 数据。原成果保存在 legacy/，不与本版实验混用。

## 目录

- output/pdf/：最终论文 PDF。
- code/question1.py：问题一，三次三折验证、缺失敏感性、0-6 假设分级与评分卡映射。
- code/question2.py：问题二，共表达图、多方法 Top-3、按风格有放回 Bootstrap 与消融。
- code/question3.py：问题三，cVAE、留出重构、缺陷约束迁移与外部对照；调用 external_analysis.py。
- code/common.py：共享数据对齐、路径、指标等工具。
- data/official/：原题附件；data/external/：新增外部数据与词典。
- results/：实际运行生成的数据、模型、诊断和校验；figures/：图表。
- data/metadata/：沿用并核查的字段映射及数值尺度记录。
- legacy/：工作目录中保留的原版代码、实验记录与论文，仅供追溯，不收入修订版交付压缩包。

## 复现

推荐 Python 3.12。安装依赖后，在本目录依次执行：

```text
python -m pip install -r requirements.txt
python code/question1.py
python code/question2.py --bootstrap 30
python code/question3.py --epochs 1200
python code/build_paper.py
```

三个问题分别有入口，但问题三需要问题一产生的感官代理模型。所有路径相对于代码位置，不依赖当前工作目录。数据不可只按行拼接：题目附件按唯一 beer 编号对齐；外部数据的 key 与 beer_id 不同，不做同一产品的匹配假设。

固定种子42，问题一重复种子另有1024、2024。CPU上运行；模型结果可能随依赖版本和浮点实现有微小差异。Bootstrap 默认30次，最高 Monte Carlo 标准误约0.091；高精度版本可改为200次以上并重建论文。论文内代码版本和输出应保持一致。

## 证据边界

1. 0-6分是训练折内拟合的单调映射假设，分级准确率只验证该假设口径，不能证明恢复了原始品评员评分。
2. 2.csv为全样本相关图先验，第二问的稳定性条件于此图；6.csv为同源摘要，不是独立验证。
3. 外部风味指标来自消费者评论词频。归一化仅减轻文本量影响，不能完全消除评论选择偏差。
4. 风格对应是显式语义假设，提供近似对应和较接近对应的分别分析；Kriek等未强行对应。
5. 生成谱的分类器识别率是内部一致性；留出重构不等于生成产品可酿造。未进行酿造或盲评实验。
6. 迁移无法满足陈旧酒花代理约束时返回原样品，并明确计为迁移失败；不得把回退样品算成成功迁移。
7. 消费者评分与评论描述同源，预测关系仅作探索，不作因果解释。验证按酒厂分组以减轻同酒厂泄漏。
