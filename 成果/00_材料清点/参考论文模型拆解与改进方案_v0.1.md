## 2. 论文模型流水线（逐步拆解）

### 2.1 预处理

1. **化学数据变换**：对 Shapiro–Wilk 检验 p<0.05（对数正态）的化学属性做**对数变换**；缺失化学测量（约占全部数据的 0.1%）用**每个属性的均值**填补；化学特征按**训练集均值/标准差**标准化。
2. **感官目标**：每位品评员的分数按该品评员的**标准差缩放并均值中心化**，得到 z 分数，再对品评员取平均；缺失值按属性均值填补。最终目标为 **z 分数**，不是 0–6 原始分。
3. **数据划分**：250 款酒按风格分层，随机 70%（175 款）训练 / 30%（75 款）测试。
4. **两种建模粒度**：逐属性单独建模（每个感官属性一个模型）+ 多输出模型（一次输出全部属性）。

### 2.2 模型清单（10 种）

| 类别 | 模型 | 实现/设置 |
| --- | --- | --- |
| 线性 | 线性回归（含一阶交互项，LR） | scikit-learn 1.2.2 |
| 线性 | Lasso 回归（含一阶交互项） | scikit-learn |
| 线性 | 偏最小二乘回归（PLSR） | scikit-learn |
| 树模型 | AdaBoost 回归（ABR） | scikit-learn |
| 树模型 | Extra Trees（ET） | scikit-learn |
| 树模型 | Gradient Boosting（GBR） | scikit-learn |
| 树模型 | Random Forest（RF） | scikit-learn |
| 树模型 | XGBoost（XGBR） | xgboost 1.7.3 |
| 核方法 | 支持向量回归（SVR） | scikit-learn |
| 神经网络 | 多层感知机（ANN / MLPRegressor） | 贝叶斯 TPE 调参（Optuna 3.2.0） |

- 超参数：**5 折交叉验证网格搜索**，以 R² 为评价指标。
- 评价：在 30% 测试集上计算多输出模型的 R²；另按“逐属性模型在每个描述符上的排名取平均”（average rank，Korneva 等提出）比较模型。

### 2.3 主要结果（论文 Table 1，测试集 R²）

| 模型 | 训练品评组 R² | 品评组平均排名 | RateBeer R² | RateBeer 平均排名 |
| --- | ---: | ---: | ---: | ---: |
| AdaBoost | 0.21 | 2.88 | 0.61 | 5.67 |
| ANN | 0.14 | 5.60 | 0.46 | 4.00 |
| Extra Trees | 0.22 | 3.02 | 0.61 | 4.67 |
| **Gradient Boosting** | **0.21** | 3.42 | **0.69** | **1.50** |
| Lasso | 0.05 | 4.94 | 0.64 | 4.33 |
| 线性回归 | −4.13 | 7.88 | −11.02 | 8.00 |
| PLSR | −0.25 | 7.56 | 0.57 | 5.33 |
| Random Forest | 0.22 | **2.86** | 0.62 | 3.50 |
| SVR | 0.18 | 6.50 | 0.59 | 6.50 |
| XGBoost | 0.22 | 4.12 | 0.62 | 2.00 |

要点：

1. **树模型整体最优**；GBR 在消费者评论（RateBeer）上明显最好（R²=0.69，逐属性最高可达约 0.75）；
2. 对**训练品评组**目标，RF/ET/AdaBoost 的平均排名略优于 GBR（2.86/3.02/2.88 vs 3.42）——说明针对本题 Q1（品评组 50 维目标），不能盲目照搬“GBR 最优”，需要按目标类型比较；
3. 线性模型在参数多、样本少时严重过拟合（训练 R²=1、测试 R² 为负）；Lasso/PLSR 的降维/正则能部分缓解；
4. 品评组数据本身的噪声与主观性导致 R² 普遍低于消费者评论数据（平均评论可“平滑”掉个体差异）；
5. 味道类（taste，如酸度、酒精）比香气类（aroma）更容易预测——香气是多化合物交互的结果；
6. 加入风格标签 **没有提升** RateBeer 模型（R²=0.66 vs 0.67）；把品评组与 RateBeer 数据合并训练也**没有提升**。

### 2.4 模型解剖（解释性）

- **MDI（平均不纯度下降）**：对 GBR（RateBeer 总体喜好模型）的 231 个特征做置换/不纯度重要性；
- **SHAP（v0.41.0）**：给出每个样品每个特征的贡献，聚合为重要性并画 summary plot；
- **PDP（部分依赖图）**：对前 6 个重要特征做一维与二维偏依赖；
- 结论：前 15 个重要特征包含 ethyl acetate（第一）、ethanol（第二）、protein、lactic acid、ethyl octanoate、ethyl phenylacetate、methanethiol、styrene、isopentyl hexanoate 等；其中部分化合物（如 methanethiol、ethyl phenylacetate）传统上被视为陈化/负面，但模型提示适量正贡献；与 Spearman 相关排名对比，15 个 SHAP 重要特征中只有 6 个进入“相关性前 15”，lactic acid 因双峰分布被相关系数完全漏掉——论文以此论证“复杂交互需要机器学习而非只看相关”。

### 2.5 模型验证（论文特色：湿实验闭环）

- 选取 Blond 与无酒精啤酒作为基酒，把模型识别的前几位化合物（ethyl acetate、ethyl hexanoate、isoamyl acetate、phenethyl acetate、ethanol、glycerol、lactic acid）按**风格内 95 分位的乙醇归一化浓度**加入；
- 训练品评组盲评（二项检验，n=20 或 13）：加入组在**总体喜好、酯香、甜度、酒精感、酒体**上显著提升；无酒精基酒在不加乙醇时同样显著提升；
- 意义：从“预测”走到“模型指导的改进”，但因只能加**点浓度组合**，不是生成完整配方。

### 2.6 论文自述局限（对本次改进最重要）

1. **共线性偏差**：GBR 在共相关变量中会“优先选择主效应最大的那个”，导致其他真正相关的化合物重要性被系统性低估（MDI 与 SHAP 都有此问题；作者用 ET 的随机性才看到部分差异）；
2. **无法推断因果**：模型只能给相关/预测，不能区分“真因果化合物”与“仅是共相关的化合物”；
3. **样本域限制**：全部为比利时商业优质啤酒，缺少“很差”的样品，导致模型在低喜好区间不可靠；
4. **无法刻画“最优浓度”**：因样品中很少出现过高浓度，PDP 在阈值以上呈平台，模型学不到“浓度过高反而变差”的非线性（而这是缺陷化合物约束的关键）；
5. **风格样本少且风格边界模糊**：加入风格变量无效，逐风格模式难学；
6. **无品评员人口学信息**；RateBeer 存在价格/从众等偏差（价格与消费者喜好 Spearman rho≈0.49，而与训练品评组无显著相关）。

## 5. 在论文模型基础上的改进方案（可直接写进论文“模型改进/创新点”）

### 5.1 问题一（化学 → 0–6 感官分级）

1. **模型层**：以论文的 10 模型基线为参照，实现其中可在本环境复现的 8 类（LR/Lasso/PLSR/ABR/ET/GBR/RF/SVR/MLP；XGBoost 用 HistGBDT 替代并在论文中注明），在**重复分层交叉验证**下重新评估；主模型按目标类型选择（论文提示 RF/ET 对品评组更稳、GBR 对总体喜好更强）。
2. **分级层（论文没有）**：把连续 z 预测映射为 0–6 整数等级，并同时报告“回归指标 + 分级指标”（精确率、±1 准确率、二次加权 Kappa）；两种映射口径（min–max 与分位等频）做敏感性分析，论文中明确写出这是**假设**（原始 0–6 分不可恢复）。
3. **缺失层**：折内中位数/迭代插补 + 缺失指示；对比“删除缺失格”“均值填补（论文做法）”“多重插补”“原生 NaN 树模型”四种策略，报告对 R²/分级指标的影响。
4. **不确定性**：重复 CV 给出指标置信区间；用 RF/ET 的树间预测方差近似单样品预测不确定度，识别“高不确定”样品（小风格、化学谱离群）。
5. **可解释性**：置换重要性 + PDP + 与 `8.xlsx` 的 SHAP/MDI 对照（标明其来自论文的 RateBeer 模型），回答“哪些化合物驱动哪些感官维度”。

### 5.2 问题二（Top-3 关键化合物与稳定性）

1. **针对论文自述的共线性偏差**：
   - 用 `2.csv` 做**模块化分组**（社区发现），把 231 个化合物分成若干共表达模块；
   - 重要性在**模块层面**聚合（模块内最大/平均重要性），Top-3 时施加**多样性约束**（同一模块最多 1 个），避免论文指出的“主效应大的变量挤掉真正相关的化合物”；
   - 采用**条件置换重要性**（在给定同模块其他变量的条件下置换）或**分组置换**，替代单纯 MDI/SHAP。
2. **稳定性**：Bootstrap 重采样 + 重复分层 CV 下统计每维度 Top-3 入选频率；跨方法（偏相关/正则系数/树重要性/官方 6.csv）两两 Jaccard；给出“稳定/边缘/不稳定”三级判定。
3. **化学合理性**：用阈值表（DMS、Diacetyl、4VG、t2n）、来源类别（酵母/酒花/麦芽/野生菌群/其他）与已知代谢通路做“命中率”与“反例”讨论；对论文中“出乎意料”的化合物（如 methanethiol 正贡献）专门讨论相关与因果的区别。
4. **外部对照**：将我们的 Top-3 与论文 MDI/SHAP 的排名做一致性分析（Spearman 排名相关/Jaccard），并在论文中明确：官方 8.xlsx 的 SHAP 来自 RateBeer 喜好模型，与本题“品评组 50 维”目标不同源，只能作方法学对照。

### 5.3 问题三（风格条件生成 + 跨风格迁移 + 缺陷约束）

论文没有生成模型，但有两条可继承的经验：①树模型可作为“化学 → 感官/喜好”的代理；②模型指导的“加料改进”是可行性验证。改进为：

1. **生成模型**：在统一浓度空间（可校准列还原为浓度后取 log，未校准列标准化）上训练**条件 VAE（cVAE）**，以 22 个风格为条件；小样本风格采用**分层/共享参数 + 风格嵌入**，避免每个风格独立建模。
2. **跨风格迁移**：在潜空间估计“源风格 → 目标风格”的方向（类别均值差或最优传输），对源样品做潜空间平移；或者直接在浓度空间做**受约束优化**（见下），两种实现互为对照。
3. **缺陷硬约束（论文的盲点）**：生成/迁移后对 DMS、Diacetyl、4VG 做**阈值投影**（超过阈值的维度压回该样品基线或阈值以下）；t2n 与 stale hops 用“相对自身基线不恶化 + 分位约束 + 4.csv 感官列约束”；这直接回应论文“模型学不到过高浓度惩罚”的局限。
4. **代理闭环**：用问题一的模型（或按论文复现的 GBR）对生成谱预测感官画像与总体评分，作为奖励/筛选；同时用风格分类器、相关结构保持度、分布距离（MMD）与化学合理性抽查做多维评价。
5. **in-silico 验证（对应论文湿实验）**：把论文“加料”实验翻译为计算实验——在若干真实基酒上按生成方向调整 top 化合物浓度，比较代理预测的感官/总体评分变化（并明确这是代理模型预测，不是真实品评）。

### 5.4 工程与可复现
