## 1. 官方模板结构（必须遵守）

| 顺序 | 章节/要素 | 模板要求与备注 |
| --- | --- | --- |
| 封面 | 队伍编号 | 模板占位 `MCB250XXXX`；**正式队伍编号待官方确认后填写** |
| 封面 | 赛道 | 模板占位“（A/B）”，本项目为**赛道 A** |
| 1 | 论文题目 | 中文题目；建议含“基于××模型/方法的××问题研究”式表达 |
| 2 | 摘 要 | 模板给出“总述 + 针对问题一/二/三 + 模型评价”四段式；要求简明点出核心思路、核心方法、使用算法、对应结论，避免过长与过多解释 |
| 3 | 关键词 | 3–5 个，覆盖方法、数据、任务关键词 |
| 4 | 问题重述 | 问题背景 + 问题提出（问题一/二/三分条） |
| 5 | 问题分析 | 问题一/二/三分别分析（明确目标、难点、思路，含问题间衔接） |
| 6 | 模型假设与符号说明 | 模型基本假设（有序列表）+ 符号说明三线表（符号/含义/单位） |
| 7 | 数据预处理 | 指标选取 + 数据清洗（缺失、异常、变换、标准化） |
| 8 | 模型建立与求解 | 每个问题下设：求解思路 → 模型建立 → 模型求解与分析（三级标题） |
| 9 | 模型分析检验 | 灵敏度分析 + 误差分析（模板将“模型检验”放在三问之后，可另设“稳健性检验”小节） |
| 10 | 模型评价与推广 | 模型优点（4 条式）、模型不足（3 条式）、模型推广（4 行以上） |
| 11 | 参考文献 | 按正文引用顺序编号；书籍/期刊/网络资源三种格式（见下） |
| 12 | 附录 | 附录 1、2、3……放主要代码；模板示例“基于××的第一问求解代码” |

**参考文献格式（模板原文）**
- 书籍：`[编号] 作者，书名，出版地：出版社，出版年.`
- 期刊：`[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年.`
- 网络资源：`[编号] 作者，资源标题，网址，访问时间（年月日）.`
- 正文引用处用方括号标号（如 `[1][3]`），书籍需标页码。

**摘要关键要求**：模板强调“针对问题一/二/三”各写清“解题核心思路、核心方法、使用算法、对应结论”，不要空泛解释，避免摘要过短或过长。

## 2. 2025 优秀论文结构（风格参考）

从 PDF 目录提取的章节组织（该文为 2025 年 MathorCup 大数据竞赛优秀论文，题目与本题不同，仅参考写作组织）：

| 顺序 | 章节 | 子节示例 |
| --- | --- | --- |
| 一 | 引言 | 研究背景与意义；国内外研究现状 |
| 二 | 问题一求解 | 问题一分析；模型建立（含方法模块小节）；模型求解；结果分析 |
| 三 | 问题二求解 | 问题二分析；模型建立；模型求解；结果分析 |
| 四 | 问题三求解 | 问题三分析（可含多个子任务/系统设计）；模型求解；结果分析 |
| 五 | 总结与展望 | 研究总结；研究展望 |
| — | 参考文献 | — |
| — | 附录 1–3 | 每个问题对应的完整 Python 代码（该文附录篇幅很长） |

**可借鉴的写作特点**：
1. 每个问题都按“**分析 → 建模 → 求解 → 结果**”闭环展开，读者容易跟随；
2. 引言包含国内外研究现状，便于引出本文方法（我们可对应写“参考论文与已有方法综述”）；
3. 附录按问题分列完整代码，正文只放关键片段与结果；
4. 图表编号与正文引用一一对应，结论量化。

## 3. 本项目论文的推荐结构（模板 + 优秀论文 + 妈妈提示词 11 部分融合）

在遵守官方模板的前提下，吸收优秀论文的“每问闭环”与附录代码，并按《妈妈提示词》补齐方法学部分：

1. **摘要**（800–1000 字，四段式：总述、问题一、问题二、问题三、模型评价）；
2. **关键词**；
3. **问题重述**（背景 + 三问）；
4. **问题分析**（三问各自的任务本质、题型归类、与前后问的衔接；对应提示词第一部分/第三部分）；
5. **模型假设与符号说明**（重要符号三线表）；
6. **数据预处理**（附件识别与字段说明、逐列变换核验、缺失与异常、0–6 分级口径假设；对应提示词“输入材料处理规则”）；
7. **问题一模型建立与求解**（求解思路 → 模型建立 → 模型求解与分析；含 10 模型基线、重复 CV、缺失敏感性、分级、诊断与解释）；
8. **问题二模型建立与求解**（共表达图、多方法集成与多样性 Top-3、稳定性与化学合理性）；
9. **问题三模型建立与求解**（条件生成、跨风格迁移、缺陷约束、代理闭环与 in-silico 验证）；
10. **模型分析检验**（各问灵敏度分析 + 误差/稳健性检验；对应提示词第七、八部分）；
11. **模型评价与推广**（结合本题结构特征与数据需求，避免套话；对应提示词第九部分）；
12. **参考文献**（真实可追溯；参考论文、方法类文献、数据来源）；
13. **附录**（每问代码清单、数据字典、补充图表；对应提示词第六部分“代码生成”）。

**统一约定**：
- 图：`图 1 …`，正文先引用后出现；每图一句结论；图注含数据来源与模型/口径；
- 表：三线表，表题在表上方；数字保留合适有效位；指标注明“均值±标准差/95% CI”；
- 公式：独立编号（1）（2）…，正文引用编号；
- 所有数字来自 `成果/results/`，不手抄；
- 代码：正文只保留关键片段，完整代码放附录/源码包，并给出运行说明与随机种子。
